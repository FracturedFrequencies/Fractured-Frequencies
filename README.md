Fractured Frequencies

Project Setup:
	
1. Unity version	Unity 6.3 LTS — 6000.3.27f1
2. Render pipeline	Universal Render Pipeline (URP)
   
Everyone must use exactly the same Unity version. 

Workflow:

1. Work on your own branch — dev/<your-name> (e.g. dev/nico). Never commit directly to master.Commit and push to your branch as often as you like. It only affects you.
2. Before merging, make sure your work has no bugs: the project opens, the scene plays, and the Console shows no red errors. Pull the latest master into your branch first and resolve any conflicts.
